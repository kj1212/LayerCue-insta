TITLE
More Screens: Stage Output Window and Layers Shown | LayerCue from Zero, Episode 16

DESCRIPTION
Run an audience screen and a stage monitor from one stage in LayerCue. There is still one stage with seven layers; each screen only chooses which layers it shows. Open the Stage output window, press Add screen, choose the stage monitor under Send to and name it Stage. A new screen that lands on the monitor LayerCue itself is on starts with its power off, so your own window is never covered. Under each preview, Layers shown picks the layers for that screen: turn B off on the stage monitor and a lyric slide with a moving background shows words on black there, while the audience still sees the video. If a stage monitor still shows the picture, that slide is set to Foreground — switch its chip to Background (or lock the list, Episode 8). The on-air chip in the status bar lists every screen with its power switch, the Layout board is a picture of your room, and an unplugged monitor says not connected and comes back on by itself.
New here? Start with Episode 1: Meet LayerCue — The Main Window.
Recorded on LayerCue 0.9.12.
Manual: https://layercue.com/docs/output/multi/ · https://layercue.com/docs/output/stage-window/
The narration is AI-generated and the music is built from GarageBand loops. The event and people in the demo are fictional. The stage monitor in this video is a virtual display.

TITLE
画面を増やす:Stage output ウィンドウと Layers shown | ゼロから LayerCue 第16回

DESCRIPTION
LayerCue の一つのステージで、客席画面とステージモニターを動かします。ステージは一つ、レイヤーも七つ一組のまま。画面ごとに、どのレイヤーを映すかだけを選びます。Stage output ウィンドウを開いて Add screen を押し、Send to でステージモニターを選び、名前を Stage にします。新しい画面が LayerCue 自身のモニターに割り当てられると電源オフで始まるので、自分のウィンドウが隠れることはありません。プレビューの下の Layers shown で画面ごとのレイヤーを選びます。ステージモニターで B をオフにすると、動く背景のある歌詞スライドがそこでは黒地に歌詞だけになり、客席には映像がそのまま映ります。ステージモニターに絵が残るなら、そのスライドは Foreground。チップを Background に切り替えます(一覧ごとの固定は第8回)。ステータスバーのオンエアチップは画面ごとの電源スイッチ付き一覧、Layout ボードは会場の見取り図。ケーブルを抜くと not connected と出て、挿し直せばひとりでに再開します。
初めての方は第1回「LayerCue のメインウィンドウ」からどうぞ。
LayerCue 0.9.12 で収録しています。
マニュアル: https://layercue.com/ja/docs/output/multi/ · https://layercue.com/ja/docs/output/stage-window/
