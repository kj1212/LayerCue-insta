One Running Order: Library. Cue sheet. Links. Find. #Shorts

DESCRIPTION
Keep every event in its own running order. A library is a real folder of presentations. A cue sheet is the running order for one event. It holds links, so you edit once, everywhere. And Find searches every name and every line.

Free while it's in beta, on Mac and Windows: https://layercue.com
